# 🏏 IPL Cricket Data Analysis & Visualization using Python

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Indian
Premier League (IPL) cricket data using Python. The analysis explores
match results, team performance, player statistics, toss decisions, and
stadium trends through data analysis and visualization.

The project aims to extract meaningful insights from IPL match data
using Python libraries and graphical representations.

## 🛠️ Technologies Used

-   **Programming Language:** Python
-   **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
-   **Environment:** Jupyter Notebook
-   **Dataset:** IPL CSV Dataset

## 📊 Key Analysis

-   Match-winning teams analysis
-   Toss decision analysis
-   Toss winner vs match winner comparison
-   Match victory margin analysis
-   Top 20 Player of the Match analysis
-   Top 3 highest run-scoring players analysis
-   Top 10 highest wicket-taking bowlers analysis
-   Highest individual score analysis
-   Most frequently used match venues analysis

## 📈 Key Features

-   Data loading and exploration
-   Dataset information and missing value analysis
-   Exploratory Data Analysis (EDA)
-   Statistical analysis using Pandas
-   Data visualization using Matplotlib and Seaborn
-   Insights into team and player performances

## 🚀 How to Run the Project

### 1. Clone the Repository

``` bash
git clone https://github.com/YOUR-USERNAME/IPL-Cricket-Data-Analysis.git
```

### 2. Navigate to the Project Folder

``` bash
cd IPL-Cricket-Data-Analysis
```

### 3. Install Required Libraries

``` bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Launch Jupyter Notebook

``` bash
jupyter notebook
```

### 5. Open the Notebook

Open `IPL.ipynb` and execute the cells.

**Note:** Place the `IPL.csv` dataset in the same directory as the
notebook before running the project.
